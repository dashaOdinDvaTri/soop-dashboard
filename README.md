# СООП — Сводка по модулям

Интерактивный прототип дашборда на тестовых данных.

Чтобы посмотреть прототип, скачайте репозиторий и откройте `index.html` в браузере.

На сводке можно выбрать территорию и период. В модуле «Администрирование» таблица подразделений поддерживает сортировку и фильтры по столбцам.
